UNSPACED HTTPS SETUP
====================

This version is prepared for HTTPS hosting.

1. Upload the contents of this folder to a static web host such as GitHub Pages.
2. The host provides the HTTPS certificate for the published site.
3. If you later own unspaced.com, configure that custom domain in the host's settings and DNS.
4. Do not put passwords, payment information, or other secrets in this static site's code.

GitHub Pages supports HTTPS and can enforce HTTPS for published sites.
See: https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https
