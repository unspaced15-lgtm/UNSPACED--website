# UNSPACED website starter

Animated, responsive clothing-brand site based on the supplied UNSPACED logo references.

Open `index.html` in a browser.

Included:
- Home / cinematic hero
- Shop
- New Drops
- About
- Lookbook
- Contact form
- Cart drawer
- Responsive layout
- UNSPACED grey / blue / purple logo assets

The product visuals, prices, social links, checkout provider, and brand story are starter content and can be replaced with the real catalogue/content.
